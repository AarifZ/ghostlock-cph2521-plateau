## Proven on this device (do not re-litigate)

1. **5.10 compact waiter** (words 0–9, `PSELECT_SHIFT=0`). JoinChang was right. Early −2 is stale.
2. **P0 linear alias** `KPHYS=0xa8000000`, delta `0x28000000`, `phys_offset=0x80000000`, 12GB RAM. Direct map 64GB (`ffffff80`…). x28 often `ffffff87/88/89` — **do not wrap** to P0.
3. **KASLR leaked** via Aristotle `boot_id` → `nfulnl_logger` (`MODE4_SLIDE`). Spray-free overlay (lock=`init_task+0x878`) lands even at 4h uptime (O29–O32). Young-boot **sprayed** oracle KP’d (O26–O28).
4. **PLAIN-STORE park:** `*selinux_state = P0(0x02BB0000)` → `enforcing=0`, `initialized≠0`. Product. Never 8-byte NULL (Z4/Z14 delayed ColorOS death).
5. **Staged fops swap** (`*MISC.fops=fake_fops`) **survives if we never open** (`MODE4_SWAP_NOCFI`). N3/N5 ALIVE. N15 HOLD when KernelSnitch gets an `ffffff80` page. High alias `ffffff88` spray fail clean (N17).
6. **`change_child` always writes `*(VALUE+8)=TARGET`.** Swap VALUE=`fake_fops` ⇒ llseek slot clobbered with `P0(MISC.fops)` ⇒ ~2 min death if anything llseeks ashmem. Repair needs a write primitive without opening the swapped node.
7. **UMH / modprobe dead:** `CONFIG_STATIC_USERMODEHELPER=y` `PATH=""`. `call_usermodehelper` executes no helper.
8. **Kernel ROOTGUARD:** `oplus_security_guard.ko` `oplus_root_check_post_handler` on `sys_exit`. `g_boot_state` 1 byte at module core+`0x3000` (`.data..ro_after_init`, own page). `is_unlocked` = LDRB+RET (any nz). Module VA punch KPs (`STRICT_MODULE_RWX`, Z47). Perf leaks hook page (off `0x3e8`) after park. Need physmap alias = need 8-byte kread of `swapper_pg_dir` (P0 `ffffff802a491000`).
9. **Leaf-NULL unhook:** `tree_pc=(funcs-8)&~3`, left=right=0, lock=`init_task+0x878`. `*__tracepoint_sys_exit.funcs=0`. Image: `__traceiter` CBZ-skips NULL funcs. **T1 `tree_pc=0` KP** (planted funcs addr in lock waiters). Lived on multiple 2026-08-29 boots.
10. **User-only PMU** (`exclude_kernel=1`, type=8) is allowed from uid 2000 under Enforcing; kernel-only is EACCES 13. Still samples kernel `REGS_INTR.x28=current`.
11. **Child uid 0 (Z33):** after StdSP disable + park + `*(child_task+cred)=init_cred`. `UID0 WIN child is root`. `/proc/22522/status` uid 0, `u:r:kernel:s0`, full caps. Parent getuid 2000. ~2 min then silent reboot (`sys.boot.reason=reboot`).
12. **Walk budget:** ~2 UAF stores per boot. Second GhostLock process after a successful walk KPs (Z5; later second-process park after oracle also KP). In-process third walk KP (Z26). In-process swap repair KP (N14).

## Remaining path (complementary primitives)

Need **one** of:

**Path 1 — kR/W (preferred for product root)**  
One surviving swap HOLD → first `pwrite` on an fd opened **before** swap → repair llseek → configfs kR/W or `pipe_physrw` → data-only:
- `P0(g_boot_state)=1` (physmap, not module VA)
- `*(task+0x778)` and `*(task+0x780)=init_cred` (self)
- `*selinux_state` already parkable without this
- KSU / persist as data

JoinChang #31 Q3 is exactly this first pwrite. No owner reply.

**Path 2 — hook-off + self cred + ColorOS mute**  
W1 leaf-NULL funcs. W2 self `*(task+0x780)=init_cred` with user-PMU x28 (high alias OK). Mute StdSP **before** fire (host `pm`). Flush `getuid_after_store` to a file. Still need MAC bypass (`setenforce` -13) for persist unless already Permissive — so this path probably still wants park, but park+cred is two walks and hook-off+cred is also two walks. **Cannot park + unhook + cred in one boot** (walk budget). Options: skip park (Enforcing, MAC stays); or unhook then cred and accept ColorOS; or kR/W after swap so walk budget does not apply.

**Path 3 — Z33 child uid0 + persist in the child**  
Already proven WIN. Extend: on `status_uid==0` (not only `self_uid==0`) run persist in the **child** (`G` command already exists). Settings mute is optional insurance against the 15s dialog; Z33 already had no dialog and still died at ~2 min.
